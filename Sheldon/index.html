Sheldon's Control System

Features - what does it do

Description of number of Relay Panels

There is a relay panel for each of the 6 tower panels. These relay panels only contain the turnout control relays for that interlocking, so the number of relays on each panel is roughly equal to the number of routes (not exactly tbe same as the number of turnouts but close). There are about 60 CTC controlled turnouts so averaged out there are about 10 relays per tower panel.

These same relays provide the route interlocking for the signals and direct the track power thru the interlocking trackage.

Only the big five track interlocking requires extra relays above these counts. That interlocking requires about 30 relays to select, signal and direct power for twelve routes. It also prevents routes that are not logical and returns turnouts to their default when they are not part of a selected route.

The rest of the interlocking relay panels are pretty simple.

There is one staging yard control panel and relay panel for all four staging yards. That controls 34 turnouts but only requires 22 relays.

There is a relay panel for each east/west pair of mainline blocks. It contains the two cab selection circuit boards, the two detectors, and 12 other relays.

Multiply that times the 8 mainline block pairs.

There are four slightly different block relay panels for the 7 different staging yards that have a similar list of components.

That covers the mainline and staging yards.

My main freight yard, passenger terminal and industrial trackage are a bit different. Only the passenger terminal is signaled with powered turnouts. The rest of the trackage has manual turnouts with ground throws that also route/control track power. Those areas have simplified cab selection that does not involve the signal system.

I can save you some time here and answer your question. Yes it is possible to build a processor based version of my exact DC system. And it has already been done.

A well known custom layout builder had a customer who wanted a DC layout. He uses the same person for many of his control systems that I worked with to make my circuit boards 25 years ago. In fact I introduced them and they worked together to build the display layout at the B&O Railroad Museum in Baltimore.

So this electronics guy, a retired robotics engineer from FORD motor company, designed and built a solid state proceesor based version of my system for this custom layout. I had the pleasure of seeing the layout befor it was shipped to the customer.

But again, it is much easier and cheaper for me to build what I have and know then it spend time and money on something new.
